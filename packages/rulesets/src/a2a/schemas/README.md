## Derived schemas (`a2a/v1.0/index.json`, `a2a/v0.3/index.json`)

These schemas are generated by `scripts/normalize-a2a-schemas.ts`. Only the `AgentCard` definition and the definitions it reaches are kept.

- **v1.0**: the upstream bundle is generated from `a2a.proto`. It has no `required` keywords, and its `$ref`s point at per-message files that the bundle does not contain. The script:
  - rewrites the `$ref`s to local pointers;
  - adds `required` from the proto's `field_behavior = REQUIRED` annotations;
  - limits proto `oneof` wrappers (for example `SecurityScheme`) to exactly one member.

  The proto-JSON snake_case aliases (`patternProperties`) are kept. Required fields are checked by their camelCase names only.

- **v0.3**: the upstream schema is draft-07. The script:
  - drops `$schema` (the schema is compiled with the 2020-12 dialect);
  - replaces the security scheme `anyOf` with a `type`-discriminated `if`/`then` chain, so errors point at the scheme that is wrong.

`validators.ts` holds standalone Ajv validators (no Ajv at runtime, browser-safe). It is generated by `scripts/compile-a2a-schemas.ts`, which `yarn compile-schemas` runs.

## Differences between v0.3 and v1.0 Agent Cards

| Concern               | v0.3                                                                                                  | v1.0                                                                                                                                                                     |
| --------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Endpoints             | `url`, `preferredTransport`, `additionalInterfaces[{url, transport}]`                                 | `supportedInterfaces[{url, protocolBinding, protocolVersion, tenant?}]`                                                                                                  |
| Protocol version      | top-level `protocolVersion`                                                                           | per interface `supportedInterfaces[].protocolVersion`                                                                                                                    |
| Extended card         | `supportsAuthenticatedExtendedCard`                                                                   | `capabilities.extendedAgentCard`                                                                                                                                         |
| Security requirements | `security: [{ "<scheme>": ["scope"] }]`                                                               | `securityRequirements: [{ "schemes": { "<scheme>": { "list": ["scope"] } } }]`                                                                                           |
| Security schemes      | discriminated by `type` (`apiKey`, `http`, `oauth2`, `openIdConnect`, `mutualTLS`); API keys use `in` | `oneof` wrapper (`apiKeySecurityScheme`, `httpAuthSecurityScheme`, `oauth2SecurityScheme`, `openIdConnectSecurityScheme`, `mtlsSecurityScheme`); API keys use `location` |
| Unknown properties    | allowed in most objects                                                                               | rejected (`additionalProperties: false`)                                                                                                                                 |

## Updating

1. Download the new upstream schema into `upstream/`. Update the table above with the source, tag, commit and the sha256 of the downloaded file.
2. Update the `required` lists in `scripts/normalize-a2a-schemas.ts` if the proto changed.
3. From `packages/rulesets`, run:

   ```sh
   ts-node -T ./scripts/normalize-a2a-schemas.ts
   prettier --write src/a2a/schemas/a2a src/a2a/schemas/upstream
   yarn compile-schemas
   ```
