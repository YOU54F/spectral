# A2A Agent Card Support

Spectral has a built-in [A2A (Agent2Agent) protocol](https://a2a-protocol.org/latest/specification/) ruleset that you can use to validate Agent Cards, the JSON documents an A2A agent publishes (usually at `/.well-known/agent-card.json`) to describe its identity, interfaces, skills and security requirements.

Add `extends: "spectral:a2a"` to your ruleset file to apply rules for A2A Agent Cards.

Both released Agent Card shapes are supported:

- **A2A v1.0** cards, which list their endpoints in `supportedInterfaces` (each with a `url`, `protocolBinding` and `protocolVersion`).
- **A2A v0.3** cards, which use a top-level `url`, `preferredTransport`, `additionalInterfaces` and `protocolVersion`.

Spectral detects the version from the shape of the card and validates it against the matching schema.

You can see a full list of the rules in this ruleset in [A2A Agent Card Rules](../reference/a2a-rules.md).
